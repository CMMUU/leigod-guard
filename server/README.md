# 加速器守护服务端

Rust/Axum 后台、MySQL 迁移与管理网页均已公开存放在本目录。数据库迁移内嵌在可执行文件中，启动时自动执行；网页资源位于 `static/`，部署时也必须携带。

**[完整自部署说明：Docker Compose 与 Linux 可执行文件](../docs/SERVER_DEPLOYMENT.md)**

- Docker：使用 [Dockerfile](Dockerfile) 和 [Compose 配置](../deploy/server/compose.yaml)，在自己的服务器构建镜像并启动数据库与应用。
- 可执行文件：从 [Server CI](https://github.com/CMMUU/leigod-guard/actions/workflows/server.yml) 下载 `server-linux-x64` 构建附件，或者用 Rust 编译；无需安装 Node.js 运行后台。
- MySQL 8.4 是必需依赖；Redis 不是本项目依赖。邮箱验证码需配置自己的 Resend 账号与已验证发信域名。
- Windows 正式版 v0.23.0 固定连接维护者的香港后台。自建后台不会自动替换该地址；自用客户端的地址修改及构建步骤见完整说明。

默认关闭服务器远程执行。此部署支持不改变现有 15 秒心跳、120 秒失联判定。

后台 0.5.0 增加独立开启的“网吧模式”：用户登录网页可为已授权账号设置连续未暂停时长，默认 24 小时，可选 1–168 小时。开启后该账号的云端任务按时长上限执行，无需网吧电脑安装守护或浏览器保持打开。当前版本的设置、计时和任务保存在 MySQL，详见 [网吧模式规则](../docs/REMOTE_PROTECTION.md#网吧模式后台-050)。

后台 **0.7.1** 支持密码账号在“账号设置 → 登录邮箱”中绑定邮箱，通过当前密码与绑定验证码确认。之后邮箱验证码登录进入原账号，管理员权限与设备归属保留；原账号密码仍可登录。验证码 10 分钟有效、60 秒后重发，与登录验证码分开保存。已被其他账号使用的邮箱不能覆盖或合并。

0.7.x 使用 MySQL；从 0.6.x/PostgreSQL 升级需先按部署指南离线迁移并保留原加密密钥。客户端单一守护选择、15 秒心跳及 120 秒失联策略保持原协议。
