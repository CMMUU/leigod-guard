# 隐私与本地数据说明

本说明适用于雷神守护当前公开版本。雷神守护由个人维护，是第三方工具；雷神账户服务及验证码服务分别由对应提供方运营。

## 会读取和处理什么

| 数据 | 用途 | 处理方式 |
| --- | --- | --- |
| 当前运行的进程文件名 | 与用户设置的游戏名单进行匹配 | 在本机读取并匹配；此监控流程不上传完整进程列表 |
| 游戏名称、`.exe` 名称、策略 | 决定自动暂停时机 | 保存在本地配置 |
| 用户填写的账户名或手机号 | 登录及显示账户状态 | 本地明文保存，并在登录请求中发送给雷神服务 |
| 密码及密码 MD5 凭据 | 密码登录，或在用户选择记住凭据时自动重登 | 登录时计算 MD5；选择记住凭据后，将 MD5 值经过 DPAPI 加密保存，而非保存密码明文 |
| token | 查询账户状态和请求暂停 | 使用时在进程内存中解密，通过 HTTPS 发送给雷神服务，本地以 DPAPI 密文保存 |
| 短信验证码、人机验证结果 | 完成账户验证 | 发送给对应登录或验证服务；人机验证结果通过短暂本地文件在程序与子进程之间传递 |
| 账户接口返回的信息 | 获取计时状态 | 响应在内存中处理，界面不展示原始账户响应；登录名称和状态等可见信息仍可能出现在截图中 |
| 状态与错误信息 | 运行诊断、反馈暂停失败 | 界面日志及本地诊断日志 |

密码登录中的 MD5 是当前服务协议的一部分，**MD5 值仍属于敏感登录凭据**，不能当作可以公开的匿名数据。短信验证码登录和手动 token 登录不保存密码，成功切换到这两种方式时会清除原先保存的密码哈希。手动输入 token 时，界面会遮蔽输入内容。

## 本地保存位置

Windows 默认配置目录为 `%APPDATA%\leigod-guard\`。

| 文件 | 内容及保留方式 |
| --- | --- |
| `config.toml` | 游戏名单、策略、明文账户名称、加密 token 和可选的加密密码哈希；保留到被修改或删除 |
| `debug.log` / `debug.log.1` | 当前与上一份诊断记录；当前文件达到约 1 MiB 时尝试轮转，不按时间自动过期 |
| `captcha-result.txt` | 验证子进程的结果，主程序正常读取后尝试删除；开始新一次子进程验证前也尝试清除旧结果 |
| `captcha-result.tmp` | 写入验证码结果时使用的过渡文件；异常中断可能残留 |
| `leigod-guard.exe.cfg` | 用户使用 RTSS 排除功能时，可能生成的临时配置，不是账户文件 |

日志可能包含游戏名称、账户状态、错误内容和本机环境信息。即使应用避免记录完整凭据，也请在分享前检查内容。界面的「清空」只清除当前界面日志，不等于删除 `debug.log` 或 `debug.log.1`。轮转文件仍然是本地诊断数据，不应直接上传。

验证码结果文件不是 DPAPI 密文。正常流程中的文件删除并非可靠安全擦除，程序崩溃、权限错误或异常中断也可能留下残余文件。WebView2 和 Windows 还可能维护自己的浏览器缓存或系统诊断数据，不由 `config.toml` 的清除操作统一管理。

## DPAPI 保护的范围

本地保存的 token 和密码哈希使用当前 Windows 用户的 DPAPI 保护。它可以降低直接读取配置文件时泄露凭据的风险，但不能抵御已能以该用户身份运行的恶意软件，也不保证保护进程内存、系统备份或账户遭到控制的情况。

不要把整个配置目录上传到 GitHub，不要将配置里的密文当作公开样例。将配置复制到另一个 Windows 用户或另一台电脑时，通常需要重新登录，不能假定密文可以迁移使用。

## 网络访问

- 登录、短信、验证码配置、账户查询和暂停操作会访问 `https://webapi.leigod.com` 及雷神服务使用的验证接口。
- 内嵌验证码窗口加载极验验证组件及其相关资源。验证服务可能按其自身政策处理网络地址、浏览器环境和验证交互等数据。
- 验证页面由程序通过本机回环地址提供，用于承载内嵌窗口，不是供局域网设备访问的控制页面。
- 当前源码没有设置项目维护者的账户数据收集服务器或遥测上传功能。用户向 Issues 主动提交的内容会按 GitHub 的规则公开展示。

HTTPS 不代表服务提供方看不到请求，也不阻止本机代理、企业网络配置或诊断工具在其权限范围内处理网络数据。非公开接口的格式和可用性由服务提供方决定。

## 退出登录与清除

在「账户」页使用「退出登录」会清空应用持有的 token、已保存的账户名与加密凭据。它是本地清除操作，**不等于撤销服务端已签发的 token**，也不会自动删除全部历史日志或浏览器缓存。

需要清除本工具的配置和诊断文件时：

1. 如果开启了自启，先在「策略」页关闭自启。
2. 使用托盘「退出」或「退出程序」完全退出工具。
3. 在资源管理器中输入 `%APPDATA%\leigod-guard\`，确认目录后删除需要清理的文件。

此操作会移除对应游戏名单、策略、登录数据和日志，之后运行工具会重新创建默认配置。如使用过 RTSS 排除功能，其安装目录内的专用排除配置需另行管理。

## 反馈前请检查

只提交复现所需的信息，移除手机号、密码、密码哈希、token、短信验证码、人机验证结果、完整账户返回内容和个人目录信息。不要上传原始 `config.toml`、验证码结果文件或未经检查的日志。
