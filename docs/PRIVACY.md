# 隐私与本地数据说明

本说明适用于 0.15.2 源码及其发布版本。雷神守护由个人维护，是第三方工具；雷神账户服务及验证码服务分别由对应提供方运营。

## 项目网站

项目介绍页由 Cloudflare Pages 托管，不提供账户登录，不查询访客的雷神账户，也不发送暂停请求。页面不包含访客统计脚本或广告；应用截图和时长卡片均为演示数据。下载脚本只向本站 `/api/downloads` 请求公开版本信息；本站通过 Pages Functions 匿名检查固定的 GitHub/Gitee 项目公开发布及校验文件，不向上游转发访客请求头或凭据。指定单源时只检查该平台。下载按钮经本站 `/download/installer` 或 `/download/portable` 跳转到对应平台的官方文件分发地址，后续访问遵循该平台的隐私规则。

访问网站仍需向托管服务发送普通 HTTP 请求，Cloudflare 可处理 IP 地址、请求路径等网络元数据；这与 Windows 应用的本地账户数据相互独立。网站不接收应用登录凭据或本机进程名单。

网站同时提供公开的 Markdown 和 AI 资料索引，内容来自首页、README 和常见问题，不包含用户账户资料。网站更新后的 IndexNow 通知由 GitHub Actions 发送，只提交公开网站地址及站点所有权验证信息，不由访客浏览器执行，也不包含访客或应用用户数据。

## 会读取和处理什么

| 数据 | 用途 | 处理方式 |
| --- | --- | --- |
| 当前运行的进程文件名 | 与用户设置的游戏名单进行匹配 | 在本机读取并匹配；此监控流程不上传完整进程列表 |
| 游戏名称、`.exe` 名称、策略 | 决定启动时检查和正常游戏退出后的自动暂停时机 | 常用游戏预设或自定义内容保存在本地配置 |
| 启动倒计时、准备游戏延后请求 | 给重启或手动准备游戏留出时间 | 倒计时和延后请求仅在当前进程内存中，退出即清除；启动等待秒数保存在本地策略 |
| 用户填写的账户名或手机号 | 登录及显示账户状态 | 本地明文保存，并在登录请求中发送给雷神服务 |
| 密码及密码 MD5 凭据 | 密码登录，或在用户选择记住凭据时自动重登 | 登录时计算 MD5；选择记住凭据后，将 MD5 值经过 DPAPI 加密保存，而非保存密码明文 |
| token | 查询账户状态和请求暂停 | 使用时在进程内存中解密，通过 HTTPS 发送给雷神服务，本地以 DPAPI 密文保存；单独开启远程保护后也通过 HTTPS 交给上海服务器加密保存 |
| 短信验证码、人机验证结果 | 完成账户验证 | 发送给对应登录或验证服务；人机验证结果通过短暂本地文件在程序与子进程之间传递 |
| 账户接口返回的信息 | 获取计时状态、首页剩余时长及查询时间 | 响应和查询时间只在内存中处理，不保存时长历史，不展示原始账户响应；登录名称、余额时长和状态等可见信息仍可能出现在截图中 |
| 状态与错误信息 | 运行诊断、反馈暂停失败 | 界面日志及本地诊断日志 |
| 当前应用版本、更新来源与检查选项 | 判断是否有可升级版本 | 选项保存在本地；以 `LeigodGuard/版本号` 作为 User-Agent；自动模式检查 GitHub 和 Gitee，单源模式只检查指定来源 |
| 游戏加加注入保护选项、本进程保护状态和已加载模块路径 | 限制第三方 DLL 进入雷神守护进程，并展示是否需要完全退出后重新打开 | 选项保存在本地；仅枚举雷神守护本进程的模块路径并在本地匹配游戏加加目录，保护状态与内部重启标记不保存、不上传 |

密码登录中的 MD5 是当前服务协议的一部分，**MD5 值仍属于敏感登录凭据**，不能当作可以公开的匿名数据。短信验证码登录和手动 token 登录不保存密码，成功切换到这两种方式时会清除原先保存的密码哈希。手动输入 token 时，界面会遮蔽输入内容。

常用游戏预设用于填写本地名单；是否触发暂停仍依据本机进程检查，不将预设选择视为已经验证游戏兼容性。游戏名称或区服不同可能对应不同的进程文件名，请核对后保存。

## 本地保存位置

Windows 默认配置目录为 `%APPDATA%\leigod-guard\`。

安装版的程序文件默认位于 `%LOCALAPPDATA%\Programs\LeigodGuard\`，与上述用户数据分开保存。安装器为当前 Windows 用户创建快捷方式和卸载记录，并将已有的本工具自启项迁移到安装目录；未开启自启时不会自动创建自启项。卸载器仅清理指向当前安装目录的自启项。升级及卸载时保留用户数据，不会自动退出雷神账户或删除游戏名单；绿色免安装版与安装版在同一 Windows 用户下使用同一份应用配置。

「绿色免安装」不表示所有数据都保存在程序目录。绿色版同样在上述用户目录写入配置和日志，用户选择开机自启时会修改 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `LeigodGuard` 项；它不创建安装版的卸载记录。

| 文件 | 内容及保留方式 |
| --- | --- |
| `config.toml` | 游戏名单、策略、更新检查选项、明文账户名称、加密 token 和可选的加密密码哈希；保留到被修改或删除 |
| `platform-remote-disable.pending` | 不含凭据的关闭请求标记，服务器确认撤销并保存状态后删除；应用退出后仍可在下次启动继续处理 |
| `platform-device.dat` | DPAPI 加密的随机安装身份、设备凭据、平台归属、上报开关、运行代次、预留心跳序号、远程保护同意状态、凭据摘要及待关闭状态；独立于平台登录会话 |
| `platform-session.dat` | 可选保存的平台会话、平台用户信息、CSRF 值和到期时间，整体经过当前 Windows 用户 DPAPI 加密；不含平台密码 |
| `platform-session.tmp` | 原子替换登录文件时的加密临时文件；异常中断可能残留，退出时尝试清除 |
| `platform-login.dat` | 当前平台来源、成功登录的邮箱/账号历史，以及用户点击「保存账号和密码」后保存的平台密码；整体由当前 Windows 用户 DPAPI 加密，不含验证码；会话过期或退出后仍保留，点击「清除已保存的账号」删除 |
| `platform-login.tmp` | 保存上述账号信息时的加密临时文件；清除已保存账号时一并删除 |
| `debug.log` / `debug.log.1` | 当前与上一份诊断记录；当前文件达到约 1 MiB 时尝试轮转，不按时间自动过期 |
| `captcha-result.txt` | 验证子进程的结果，主程序正常读取后尝试删除；开始新一次子进程验证前也尝试清除旧结果 |
| `captcha-result.tmp` | 写入验证码结果时使用的过渡文件；异常中断可能残留 |
| `leigod-guard.exe.cfg` | 用户使用 RTSS 排除功能时，可能生成的临时配置，不是账户文件 |

日志可能包含游戏名称、账户状态、错误内容和本机环境信息。即使应用避免记录完整凭据，也请在分享前检查内容。界面的「清空」只清除当前界面日志，不等于删除 `debug.log` 或 `debug.log.1`。轮转文件仍然是本地诊断数据，不应直接上传。

验证码结果文件不是 DPAPI 密文。正常流程中的文件删除并非可靠安全擦除，程序崩溃、权限错误或异常中断也可能留下残余文件。WebView2 和 Windows 还可能维护自己的浏览器缓存或系统诊断数据，不由 `config.toml` 的清除操作统一管理。

### 游戏加加注入保护

「阻止游戏加加向本工具注入」默认关闭。开启后，本工具先在本次进程环境中设置游戏加加 Vulkan 隐式层的禁用变量作为辅助，再使用 Windows 进程创建缓解策略重新启动受保护的雷神守护主进程；内部命令行标记仅用于确认这次受保护重启。环境变量可能由本工具启动的子进程继承，但不会写入用户或系统环境变量。Vulkan 变量本身不能阻止 DirectX 或其他通用注入。更改开关后须从托盘完全退出雷神守护并重新打开才会生效或撤销，不需要管理员权限。

严格 DLL 加载策略只作用于新启动的雷神守护主进程，不改变游戏进程；保护流程不读取或修改游戏加加的文件、注册表或配置，不结束、暂停或控制游戏加加进程，也不新增网络请求。游戏加加在其他游戏中的功能仍由游戏加加自身运行。Windows 的严格加载策略还会阻止其他不属于 Microsoft、Microsoft Store 或 WHQL 信任范围的 DLL，可能影响其他 OSD、录屏或输入法插件；出现异常时可关闭开关并完全退出后重新打开。是否成功屏蔽请以策略页状态及本机实测为准。

### 更新缓存与备份

点击下载更新后，会在 `%LOCALAPPDATA%\LeigodGuard\updates\update-*\` 创建专用暂存目录。该目录可能包含下载的安装 EXE 或 ZIP、更新助手、解压文件、`plan.json` 更新计划、成功或错误记录，以及安装版的 `setup.log`。更新计划记录版本、文件校验值、程序路径和待退出进程的信息，不保存雷神账户凭据；日志可能包含本机路径。

绿色免安装版另在原程序目录下创建 `.leigod-update-*\`，用于替换文件和保留旧文件备份。正常的替换失败会尝试恢复已改动的文件；若系统中断或恢复受阻，备份可用于人工处理。缓存与备份目前保留在磁盘上，不按时间自动清理。确认新版本运行正常后，请先完全退出程序，再清理对应的更新暂存目录和绿色版旧备份；更新尚未结束或需要恢复旧文件时不要删除它们。不要把这些目录当作问题反馈附件整体上传。

## DPAPI 保护的范围

本地保存的 token 和密码哈希使用当前 Windows 用户的 DPAPI 保护。它可以降低直接读取配置文件时泄露凭据的风险，但不能抵御已能以该用户身份运行的恶意软件，也不保证保护进程内存、系统备份或账户遭到控制的情况。

不要把整个配置目录上传到 GitHub，不要将配置里的密文当作公开样例。将配置复制到另一个 Windows 用户或另一台电脑时，通常需要重新登录，不能假定密文可以迁移使用。

## 网络访问

- 在「关于与更新」点击「检查更新」，或启用默认关闭的「启动时自动检查更新」后启动应用，会匿名检查公开版本信息。0.10.0 起默认「自动选择（国内优先）」并行访问 GitHub 和 Gitee；「仅 GitHub」或「仅 Gitee」只访问指定来源，旧配置保存的明确选择会保留。GitHub 使用 `https://api.github.com/repos/CMMUU/leigod-guard/releases/latest`；Gitee 使用 `https://gitee.com/api/v5/repos/cmmuu/leigod-guard/releases` 列表及相应版本的附件列表。切换本身不发起检查。请求包含当前应用版本的 User-Agent，服务会接收到普通网络请求中的 IP 地址等连接信息。不发送雷神账户名、密码、token、游戏名单或本地配置，不需要 GitHub 或 Gitee 凭据。
- 只有点击「下载并自动更新」才下载校验文件和对应安装 EXE / 绿色 ZIP。自动模式下载失败时，会尝试另一来源的同一版本并显示切换状态；必要时使用 GitHub `releases/tags/指定标签` 或 Gitee 列表查询精确版本。单源模式不会回退至另一服务。GitHub 使用本仓库的 Release 资产 API 和官方分发地址；Gitee 使用本仓库的附件 API，允许跳转至 `foruda.gitee.com/attach_file/`。各次下载核对文件名、大小及 SHA-256，备用源不得更改已确认的校验值或混用残片；完整性校验不是独立的发布者签名。关闭启动检查后，仍可手动检查和下载。完整说明见 [自动更新规则](https://github.com/CMMUU/leigod-guard/blob/v0.10.1/docs/UPDATES.md)。
- 安装版检测到 WebView2 Runtime 缺失时，会运行随包的微软安装引导程序，由它联网下载并安装运行时。此过程访问微软的下载服务，运行时及其更新按微软自身的许可和隐私政策处理。
- 登录、短信、验证码配置、账户查询和暂停操作会访问 `https://webapi.leigod.com` 及雷神服务使用的验证接口。
- 恢复已保存的登录态后，通过既有 `/api/user/info` 接口自动查询一次账户状态和剩余时长；重新打开面板、从托盘打开或进入账户页时也会刷新，快速重复打开按最短 5 秒间隔合并。首页和账户页在前台停留期间每 60 秒查询一次；切到其他页面、失去焦点或隐藏到托盘后不发起这种定时查询。用户仍可手动刷新，登录及暂停后的查询也会更新首页。查询不会调用暂停或恢复接口，不引入额外服务；使用本次响应的服务器时间处理活动时长。失败后有间隔限制，退出或更换账号清除原来的时长与查询时间。
- 毛玻璃使用程序生成并高斯模糊后缓存的应用内背景，不读取壁纸、桌面截图或其他应用画面，不向外发送图像。
- `strategy.pause_on_startup` 默认开启，旧配置缺少该字段时也采用开启值。0.8.0 增加 `strategy.startup_grace_secs`，新旧配置默认等待 180 秒。启动时自动暂停开启、名单非空且进程名全部有效，连续等待结束仍无名单游戏时，使用既有雷神接口尝试暂停计时；不上传完整进程列表。准备游戏按钮仅延后本地检查，不请求开启加速，不新增账户接口或遥测。名单为空、存在无效进程名或相关开关关闭时跳过该次启动检查。此选项与「启动时自动检查更新」相互独立。
- 内嵌验证码窗口加载极验验证组件及其相关资源。验证服务可能按其自身政策处理网络地址、浏览器环境和验证交互等数据。
- 验证页面由程序通过本机回环地址提供，用于承载内嵌窗口，不是供局域网设备访问的控制页面。
- 「平台账号」通过 HTTPS 连接上海平台 `https://111.229.216.86`。验证码方式发送邮箱、验证码和本次请求标识；密码方式发送平台账号和密码。邮箱验证成功后自动创建普通用户；邮箱不会自动合并或接管同名密码账号。验证码不落盘，平台密码仅在用户点击「保存账号和密码」时加密保存。
- 邮箱与密码登录表单各自维护输入值。首次使用没有预设邮箱，成功登录后会加密记录对应方式的邮箱或账号，旧版有效会话可回填对应账号；仅输入、发送验证码或失败登录不会自动记入历史。账号密码保存与 30 天会话独立，只回填、不自动登录；同账号更改密码后需重新点击保存。
- 邮件由 Resend 发送，服务商接收收件邮箱、验证码邮件内容及正常投递所需信息。后台保存规范化邮箱、验证时间、带服务端密钥的验证码摘要、请求限频记录和登录审计；验证码 10 分钟有效，最多尝试 5 次，仅可兑换一次。不会在应用日志中记录验证码或邮件内容。
- 勾选记住登录状态时，`platform-session.dat` 使用当前 Windows 用户的 DPAPI 加密保存平台会话，有效期最多 30 天；未勾选为 24 小时且不保存此会话文件。平台身份在恢复时及平台页前台停留时每 60 秒校验，校验不会延长到期时间。
- 登录平台后自动绑定本机，也可通过网页的一次性配对码手动绑定。`platform-device.dat` 单独加密保存随机安装标识、设备凭据、所属平台账号、上报开关及心跳计数。服务器只存安装标识和设备凭据的摘要。设备授权独立于平台会话，绑定后在托盘运行及重启后继续上报，每 15 秒发送设备名、版本、是否检测到游戏和准备游戏保护秒数。进程检测失败用未知状态，不当作没有游戏。
- 当前雷神账号经本机登录并成功查询后，客户端上报账号标识的 SHA-256 摘要与最后 4 位脱敏标签供关联显示。此摘要不是匿名化保证，低熵账号仍可能被猜测；未授权时平台不接收雷神 token；平台不接收雷神密码、余额、游戏名单或完整进程列表。退出雷神账号后，下次心跳清除显示关联。明确开启远程保护后的凭据处理见下项。
- **远程失联保护默认关闭。** 客户端单独勾选授权并开启后，通过固定上海 HTTPS 地址上传当前 `account_token`，仅首次授权或凭据变化时上传，不放进心跳或 URL。token 具有雷神账号权限，并非雷神官方签发的“仅暂停”范围。服务器向雷神查询并验证账号唯一 ID，同一雷神账号不能被不同平台用户占用。
- 上海服务采用 AES-256-GCM 随机 nonce 与账号绑定的认证加密，密钥通过独立受限文件提供，与数据库分离。网页、管理员接口、审计不返回原始 token、密码或密文。服务器按雷神既有协议请求其 HTTPS 接口，该协议在查询参数中携带 token，服务禁止重定向且不记录请求 URL、原始响应或网络错误详情。
- 全部授权设备持续失联 120 秒、准备期结束后，服务器可查询账户状态并请求暂停，再查询结果；每个失联周期只有一个有效任务，有限重试。服务器不会使用用户密码重登，也不会自动恢复计时。停止、退出或网页撤销取消未发出任务；已经发送的雷神请求无法撤回。
- 撤销最后一台授权设备后，在线数据库删除当前 token 密文；设备/账号归属、脱敏标识和审计仍保留，任务历史保留 30 天（当前失联周期的去重记录保留到新周期）。备份中的历史密文按备份保留期淘汰，关闭功能不等于撤销雷神已签发的 token。异地备份须单独加密，解密私钥与备份介质分开；部署与恢复记录见运维文档。

- 平台接收连接 IP、账号会话活动、设备状态和审计；设备活跃与平台登录分别统计。没有保存的平台会话或已激活的设备授权时，启动不连接平台。普通用户只能查询、撤销和解除自己的设备，管理员可查看全局设备与用户记录。
- 用户向 Issues 主动提交的内容会按 GitHub 的规则公开展示。

内嵌 WebView2 组件包含默认启用的 **Microsoft Defender SmartScreen**，会收集并向微软发送用户信息，具体范围及用途见 [微软隐私声明](https://privacy.microsoft.com/en-us/privacystatement) 和 [SmartScreen 隐私说明](https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen)。WebView2 也会收集必要诊断数据；可选诊断数据由 Windows 的「诊断和反馈」设置控制，关闭可选数据并不代表关闭全部必要数据。详见 [微软 WebView2 数据与隐私文档](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/data-privacy)。

## 退出登录与清除

在「账户」页使用「退出登录」会清空应用持有的 token、已保存的账户名与加密凭据。它是本地清除操作，**不等于撤销服务端已签发的 token**，也不会自动删除全部历史日志或浏览器缓存。

「平台账号」页的「退出平台账号」另行清除 `platform-session.dat` 与临时文件，并尝试撤销该平台会话。断网时撤销不能保证成功，页面会提示重试；平台会话的服务器有效期记住时最多 30 天，未记住时 24 小时。退出平台账号会请求关闭本机远程保护并停止设备上报，不清除雷神加速器账号；设备历史记录和加密身份文件仍保留。网页撤销立即使设备凭据失效，解除绑定后可归属其他账号。退出或手动重新登录雷神加速器账号会请求撤销本机远程保护，不退出平台账号；下次心跳同步显示关联。断网或服务器未确认时仍可能触发失联暂停，客户端持久化关闭请求并重试。账号停用和后台修改密码会使服务器拒绝原平台会话。

平台「退出平台账号」保留 `platform-login.dat` 中的账号、邮箱历史与显式保存的密码，便于下次登录。「清除已保存的账号」删除该文件及临时文件，并清空表单；不撤销现有会话、不停止设备上报或保护。仍有效的会话包含账号身份，重启后可再次作为账号回填来源；如需一并移除，请同时退出平台账号。

仅卸载雷神守护不会清除 `%APPDATA%\leigod-guard\`。如需在卸载前清除账户信息，可先在应用中退出登录，并在平台页清除已保存的账号。卸载本工具也不会卸载可能由其他应用共用的 WebView2 Runtime。

需要清除本工具的配置和诊断文件时：

1. 如果开启了自启，先在「策略」页关闭自启。
2. 使用托盘「退出」或「退出程序」完全退出工具。
3. 在资源管理器中输入 `%APPDATA%\leigod-guard\`，确认目录后删除需要清理的文件。

此操作会移除对应游戏名单、策略、登录数据和日志，之后运行工具会重新创建默认配置。如使用过 RTSS 排除功能，其安装目录内的专用排除配置需另行管理。
