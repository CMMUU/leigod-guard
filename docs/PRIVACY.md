# 隐私与本地数据说明

本说明适用于雷神守护当前公开版本。雷神守护由个人维护，是第三方工具；雷神账户服务及验证码服务分别由对应提供方运营。

## 会读取和处理什么

| 数据 | 用途 | 处理方式 |
| --- | --- | --- |
| 当前运行的进程文件名 | 与用户设置的游戏名单进行匹配 | 在本机读取并匹配；此监控流程不上传完整进程列表 |
| 游戏名称、`.exe` 名称、策略 | 决定启动时检查和正常游戏退出后的自动暂停时机 | 常用游戏预设或自定义内容保存在本地配置 |
| 启动倒计时、准备游戏延后请求 | 给重启或手动准备游戏留出时间 | 倒计时和延后请求仅在当前进程内存中，退出即清除；启动等待秒数保存在本地策略 |
| 用户填写的账户名或手机号 | 登录及显示账户状态 | 本地明文保存，并在登录请求中发送给雷神服务 |
| 密码及密码 MD5 凭据 | 密码登录，或在用户选择记住凭据时自动重登 | 登录时计算 MD5；选择记住凭据后，将 MD5 值经过 DPAPI 加密保存，而非保存密码明文 |
| token | 查询账户状态和请求暂停 | 使用时在进程内存中解密，通过 HTTPS 发送给雷神服务，本地以 DPAPI 密文保存 |
| 短信验证码、人机验证结果 | 完成账户验证 | 发送给对应登录或验证服务；人机验证结果通过短暂本地文件在程序与子进程之间传递 |
| 账户接口返回的信息 | 获取计时状态 | 响应在内存中处理，界面不展示原始账户响应；登录名称和状态等可见信息仍可能出现在截图中 |
| 状态与错误信息 | 运行诊断、反馈暂停失败 | 界面日志及本地诊断日志 |
| 当前应用版本、更新检查选项 | 判断是否有可升级版本 | 选项保存在本地；检查更新时以 `LeigodGuard/版本号` 作为 User-Agent 向 GitHub 发送请求 |
| 游戏加加注入保护选项、本进程保护状态和已加载模块路径 | 限制第三方 DLL 进入雷神守护进程，并展示是否需要完全退出后重新打开 | 选项保存在本地；仅枚举雷神守护本进程的模块路径并在本地匹配游戏加加目录，保护状态与内部重启标记不保存、不上传 |

密码登录中的 MD5 是当前服务协议的一部分，**MD5 值仍属于敏感登录凭据**，不能当作可以公开的匿名数据。短信验证码登录和手动 token 登录不保存密码，成功切换到这两种方式时会清除原先保存的密码哈希。手动输入 token 时，界面会遮蔽输入内容。

常用游戏预设用于填写本地名单；是否触发暂停仍依据本机进程检查，不将预设选择视为已经验证游戏兼容性。游戏名称或区服不同可能对应不同的进程文件名，请核对后保存。

## 本地保存位置

Windows 默认配置目录为 `%APPDATA%\leigod-guard\`。

安装版的程序文件默认位于 `%LOCALAPPDATA%\Programs\LeigodGuard\`，与上述用户数据分开保存。安装器为当前 Windows 用户创建快捷方式和卸载记录，并将已有的本工具自启项迁移到安装目录；未开启自启时不会自动创建自启项。卸载器仅清理指向当前安装目录的自启项。升级及卸载时保留用户数据，不会自动退出雷神账户或删除游戏名单；绿色免安装版与安装版在同一 Windows 用户下使用同一份应用配置。

「绿色免安装」不表示所有数据都保存在程序目录。绿色版同样在上述用户目录写入配置和日志，用户选择开机自启时会修改 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `LeigodGuard` 项；它不创建安装版的卸载记录。

| 文件 | 内容及保留方式 |
| --- | --- |
| `config.toml` | 游戏名单、策略、更新检查选项、明文账户名称、加密 token 和可选的加密密码哈希；保留到被修改或删除 |
| `debug.log` / `debug.log.1` | 当前与上一份诊断记录；当前文件达到约 1 MiB 时尝试轮转，不按时间自动过期 |
| `captcha-result.txt` | 验证子进程的结果，主程序正常读取后尝试删除；开始新一次子进程验证前也尝试清除旧结果 |
| `captcha-result.tmp` | 写入验证码结果时使用的过渡文件；异常中断可能残留 |
| `leigod-guard.exe.cfg` | 用户使用 RTSS 排除功能时，可能生成的临时配置，不是账户文件 |

日志可能包含游戏名称、账户状态、错误内容和本机环境信息。即使应用避免记录完整凭据，也请在分享前检查内容。界面的「清空」只清除当前界面日志，不等于删除 `debug.log` 或 `debug.log.1`。轮转文件仍然是本地诊断数据，不应直接上传。

验证码结果文件不是 DPAPI 密文。正常流程中的文件删除并非可靠安全擦除，程序崩溃、权限错误或异常中断也可能留下残余文件。WebView2 和 Windows 还可能维护自己的浏览器缓存或系统诊断数据，不由 `config.toml` 的清除操作统一管理。

### 游戏加加注入保护

「阻止游戏加加向本工具注入」默认关闭。开启后，本工具先在本次进程环境中设置游戏加加 Vulkan 隐式层的禁用变量作为辅助，再使用 Windows 进程创建缓解策略重新启动受保护的雷神守护主进程；内部命令行标记仅用于确认这次受保护重启。环境变量可能由本工具启动的子进程继承，但不会写入用户或系统环境变量。Vulkan 变量本身不能阻止 DirectX 或其他通用注入。更改开关后须从托盘完全退出雷神守护并重新打开才会生效或撤销，不需要管理员权限。

严格 DLL 加载策略只作用于新启动的雷神守护主进程，不改变游戏进程；保护流程不读取或修改游戏加加的文件、注册表或配置，不结束、暂停或控制游戏加加进程，也不新增网络请求。游戏加加在其他游戏中的功能仍由游戏加加自身运行。Windows 的严格加载策略还会阻止其他不属于 Microsoft、Microsoft Store 或 WHQL 信任范围的 DLL，可能影响其他 OSD、录屏或输入法插件；出现异常时可关闭开关并完全退出后重新打开。是否成功屏蔽请以策略页状态及本机实测为准。

### 更新缓存与备份

点击下载更新后，会在 `%LOCALAPPDATA%\LeigodGuard\updates\update-*\` 创建专用暂存目录。该目录可能包含下载的安装 EXE 或 ZIP、更新助手、解压文件、`plan.json` 更新计划、成功或错误记录，以及安装版的 `setup.log`。更新计划记录版本、文件校验值、程序路径和待退出进程的信息，不保存雷神账户凭据；日志可能包含本机路径。

绿色免安装版另在原程序目录下创建 `.leigod-update-*\`，用于替换文件和保留旧文件备份。正常的替换失败会尝试恢复已改动的文件；若系统中断或恢复受阻，备份可用于人工处理。缓存与备份目前保留在磁盘上，不按时间自动清理。确认新版本运行正常后，请先完全退出程序，再清理对应的更新暂存目录和绿色版旧备份；更新尚未结束或需要恢复旧文件时不要删除它们。不要把这些目录当作问题反馈附件整体上传。

## DPAPI 保护的范围

本地保存的 token 和密码哈希使用当前 Windows 用户的 DPAPI 保护。它可以降低直接读取配置文件时泄露凭据的风险，但不能抵御已能以该用户身份运行的恶意软件，也不保证保护进程内存、系统备份或账户遭到控制的情况。

不要把整个配置目录上传到 GitHub，不要将配置里的密文当作公开样例。将配置复制到另一个 Windows 用户或另一台电脑时，通常需要重新登录，不能假定密文可以迁移使用。

## 网络访问

- 在「关于与更新」点击「检查更新」，或启用默认关闭的「启动时自动检查更新」后启动应用，会匿名访问 `https://api.github.com/repos/CMMUU/leigod-guard/releases/latest`。请求包含当前应用版本的 User-Agent；GitHub 也会接收到普通网络请求中的 IP 地址等连接信息。此检查不发送雷神账户名、密码、token、游戏名单或本地配置。
- 只有点击「下载并更新」才会从本仓库 GitHub Release 及其官方资产分发地址下载校验文件和对应安装 EXE / 绿色 ZIP。程序核对文件名、大小及 SHA-256；校验用于检测文件完整性，不是独立的发布者签名。关闭启动时的更新检查后，仍可手动检查和下载更新。
- 安装版检测到 WebView2 Runtime 缺失时，会运行随包的微软安装引导程序，由它联网下载并安装运行时。此过程访问微软的下载服务，运行时及其更新按微软自身的许可和隐私政策处理。
- 登录、短信、验证码配置、账户查询和暂停操作会访问 `https://webapi.leigod.com` 及雷神服务使用的验证接口。
- `strategy.pause_on_startup` 默认开启，旧配置缺少该字段时也采用开启值。0.8.0 增加 `strategy.startup_grace_secs`，新旧配置默认等待 180 秒。启动时自动暂停开启、名单非空且进程名全部有效，连续等待结束仍无名单游戏时，使用既有雷神接口尝试暂停计时；不上传完整进程列表。准备游戏按钮仅延后本地检查，不请求开启加速，不新增账户接口或遥测。名单为空、存在无效进程名或相关开关关闭时跳过该次启动检查。此选项与 GitHub 的「启动时自动检查更新」相互独立。
- 内嵌验证码窗口加载极验验证组件及其相关资源。验证服务可能按其自身政策处理网络地址、浏览器环境和验证交互等数据。
- 验证页面由程序通过本机回环地址提供，用于承载内嵌窗口，不是供局域网设备访问的控制页面。
- 当前源码没有设置项目维护者的账户数据收集服务器或遥测上传功能。用户向 Issues 主动提交的内容会按 GitHub 的规则公开展示。

内嵌 WebView2 组件包含默认启用的 **Microsoft Defender SmartScreen**，会收集并向微软发送用户信息，具体范围及用途见 [微软隐私声明](https://privacy.microsoft.com/en-us/privacystatement) 和 [SmartScreen 隐私说明](https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen)。WebView2 也会收集必要诊断数据；可选诊断数据由 Windows 的「诊断和反馈」设置控制，关闭可选数据并不代表关闭全部必要数据。详见 [微软 WebView2 数据与隐私文档](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/data-privacy)。

安装引导程序及 WebView2 Runtime 适用单独的微软条款，随包保存的 [许可全文与来源](../licenses/webview2-runtime/README.md) 不属于本项目 MIT 许可的授权范围。

应用内更新的辅助进程本身不发送雷神暂停请求；完成更新后重新启动的应用会按上述启动策略处理，符合条件时可能暂停计时。更新间隔内工具不监控游戏，已经消耗的时长无法追回。

HTTPS 不代表服务提供方看不到请求，也不阻止本机代理、企业网络配置或诊断工具在其权限范围内处理网络数据。非公开接口的格式和可用性由服务提供方决定。

## 退出登录与清除

在「账户」页使用「退出登录」会清空应用持有的 token、已保存的账户名与加密凭据。它是本地清除操作，**不等于撤销服务端已签发的 token**，也不会自动删除全部历史日志或浏览器缓存。

仅卸载雷神守护不会清除 `%APPDATA%\leigod-guard\`。如需在卸载前清除账户信息，可先在应用中退出登录。卸载本工具也不会卸载可能由其他应用共用的 WebView2 Runtime。

需要清除本工具的配置和诊断文件时：

1. 如果开启了自启，先在「策略」页关闭自启。
2. 使用托盘「退出」或「退出程序」完全退出工具。
3. 在资源管理器中输入 `%APPDATA%\leigod-guard\`，确认目录后删除需要清理的文件。

此操作会移除对应游戏名单、策略、登录数据和日志，之后运行工具会重新创建默认配置。如使用过 RTSS 排除功能，其安装目录内的专用排除配置需另行管理。

## 反馈前请检查

只提交复现所需的信息，移除手机号、密码、密码哈希、token、短信验证码、人机验证结果、完整账户返回内容和个人目录信息。不要上传原始 `config.toml`、验证码结果文件或未经检查的日志。
