# 外星仔接入说明（0.17.0）

状态：0.16.1 起提供本机功能；用户于 2026-09-23 反馈已测试可用，未逐项提供测试场景。0.17.0 / 后台 0.4.0 新增服务器适配，真实服务器授权与失联暂停尚待验收。默认关闭，保留试验性标记。

## 使用步骤

1. 在“加速器账户”选择“外星仔加速器”，使用本人手机号、密码登录，或导入本人已有 Authorization。密码不保存，令牌使用 Windows DPAPI 加密。
2. 在外星仔官方客户端手动暂停、刷新，确认计时已经暂停。
3. 返回守护工具点击“我已在官方暂停，读取并校准”。这一步只查询，不发送暂停或恢复请求；未返回有效暂停状态时无法开启。
4. 勾选“启用外星仔自动暂停”。使用现有游戏名单、启动宽限期、退出宽限期和自动暂停总开关。
5. 暂停动作前再次检查游戏与最新配置，暂停后重新查询官方状态；未确认即报告失败，进入冷却期，不显示成功。

雷神和外星仔可以分别登录、同时开启。外星仔可单独退出或禁用。托盘“立即暂停”作用于已配置的两个账号；主页原有雷神暂停按钮仍作用于雷神，外星仔账户页有独立暂停按钮。准备游戏延后会保护相应启动检查，不启动加速、不恢复计时。

首次校准来自用户明确确认的官方状态，不内置猜测的暂停值。校准不会自动启用守护；重新登录清除校准。PC 免费时长与可暂停时长分别显示，具体免费时长到期规则由官方决定，不能承诺暂停免费时长的有效期。

## 范围与兼容

- 本机：游戏退出暂停、启动补查、手动暂停、正常关机尽力暂停。
- 平台服务器可分别授权雷神和外星仔，互不覆盖。外星仔首次授权前须先在官方客户端暂停、读取校准，然后到“平台账号”明确同意上传凭据并开启。未授权时不上传外星仔令牌。
- 授权包含令牌、随机设备标识和校准值，不包含密码。服务器通过官方 `/account/v1/my_profile` 验证账号身份，通过 PC 时长接口确认校准状态；缺少身份、未知状态或校准不符均拒绝授权。
- 同一外星仔账号任一受保护设备在线则不暂停；全部持续失联 120 秒且准备期结束才尝试。请求前复核、请求后查询确认，网络或官方接口变化可能导致失败。
- 退出/重新登录/重新校准外星仔会请求关闭其远程授权；断网时关闭未确认仍可能暂停。网页关闭按加速器区分，撤销整台设备会关闭两个授权。
- 回退到旧客户端后，服务端收到不支持外星仔的旧格式心跳时撤销该设备外星仔授权，保留雷神授权。
- 没有外星仔账号或没有完成校准时，不发送外星仔账号请求。
- 原配置目录、安装 AppId、EXE 和发布资产名、GitHub/Gitee 仓库、更新来源规则保持兼容；升级移除旧名称快捷方式并建立新名称。
- 配置中的外星仔数据位于 `[etalien]`；没有该段的旧版配置按关闭处理。

- 用户指定官网：https://www.et001.com/
- 官方公开网页脚本：`https://www.et001.com/_nuxt/8a49178.js`（研究时记录；发布散列可能变化），确认官方 API 主机与签名规则。
- 官方公开 Windows 1.26.11 安装包：`https://file.et-cdn.com/upd/pc/ETAlienBooster_setup_1.26.11.exe`；仅解包读取资料，未执行安装。客户端包含 `/v2/account/login`、`/v2/account/remain/duration`、`/v2/account/update/pause/state` 及 `UpdatePauseStateRequest`；同一官方客户端还包含 `/account/v1/my_profile` 资料查询路径。
- 协议字段线索：[JiangXu26710/etalien-auto](https://github.com/JiangXu26710/etalien-auto)，MIT。该项目注明功能已失效，因此仅作为协议字段线索，不视为可用性证明。未复制奖励/广告相关功能。
- 请求固定官方 HTTPS 主机，禁止重定向，限时、限响应大小；采用 Protobuf，错误不输出响应正文或凭据。

替代实现是硬编码推测的暂停枚举，改动更少，但有发错状态的风险。本实现选择独立账号、显式校准、暂停前复核和暂停后查询。未来取得官方稳定协议或通过专门测试账号确认全部状态后，才能简化首次校准。

真实验收须在未加速的专门测试账号/空闲时间完成：登录、官方暂停校准、短时开启计时后手动暂停、游戏退出宽限期、游戏重启取消暂停、令牌失效、退出账户、关闭策略、关机；同时确认雷神与平台保护未回归。不在用户正在游戏的机器上执行测试。
