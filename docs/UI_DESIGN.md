# 界面设计与验证

0.9.0 使用已确认的 Apple 浅色概念：左侧品牌导航、启动保护卡片与规则摘要、分组游戏列表、底部重启说明。程序继续使用 Rust / egui 原生界面和 Windows 窗口操作。

## 设计系统

- 主内容使用浅蓝、薄荷绿、淡紫色的应用内背景；在 384 × 256 纹理上执行 sigma 20 的高斯模糊，初始化时上传缓存，后续帧只采样。白色卡片透明度 180/255，侧栏 95/255，带细白色高光边线和柔和阴影；不使用桌面采集或系统透明窗口。
- 文字 `#171B25`、次级文字 `#636C7D`、边线 `#E5E8ED`、主操作蓝色 `#007AFF`、计时圆环青绿 `#2CC9AD`。文字与交互控件不参与模糊。
- 页面标题 27 px、卡片标题 22 px、正文 / 控件 15 px、辅助文字 12 px；使用 Windows 系统 Segoe UI 和微软雅黑字体，不分发 Apple 字体。
- 卡片圆角 18 px、按钮 9 px、导航行 11 px；统一线性图标，避免混用彩色 emoji。保留项目原有盾牌图标。
- 游戏条目采用独立分组列表，显示名称、进程和实际观测状态。图标使用本项目绘制的文字标识，不随包分发游戏厂商图标；自定义游戏也遵循相同样式。
- 宽窗口并排显示启动保护与规则摘要；窄窗口纵向排列。侧栏随窗口缩小，内容纵向滚动，兼容 680 × 460 的最小窗口。

## 交互与真实状态

首页总开关写入原有策略；延后和立即暂停仍使用原有监控指令，视觉重排不增加自动恢复或停止加速功能。规则摘要读取实际配置值，避免把概念图中的 3 分钟 / 90 秒写死。未完成检测、进程检测失败、空名单、无效名单和自动暂停关闭均显示对应状态，不能假装正在守护或已暂停。

「添加游戏」打开表单，保留热门游戏下拉、自定义输入和进程选择；每行的更多菜单可移除该条目。账户三种登录方式、托盘行为、OSD 屏蔽和双来源更新保留。

0.11.2 起，游戏退出宽限期文字由后台发布的实际退出检测起点和宽限秒数计算，利用既有界面重绘逐秒显示；不依赖默认 3 秒一次的进程扫描更新整段文字。使用单调时钟、向上取整并在零处停止，结束时显示等待复核；后台状态切换会清除旧倒计时。显示计算不发起进程扫描、账户查询或暂停请求。

启动保护卡片左侧标题下方新增「账户剩余时长」，用时、分、秒展示最近一次查询结果（例如「8941 时 15 分 01 秒」）；右侧圆环仍仅表示启动等待。小于一分钟显示具体秒数（例如「0 时 00 分 59 秒」），只有接口确实返回零值才展示「0 时 00 分 00 秒」。下方显示查询时间和「刷新时长」，未登录时显示「去登录」。查询期间保留旧值并标明上次结果；失败清除旧值，缺失或异常时长字段显示暂不可用，不因活动到期字段存在而隐藏正常余额。该数值不在本机模拟逐秒扣费。恢复登录态后查询一次，打开面板或进入账户页自动刷新；前台首页与账户页每 60 秒查询，失焦或托盘期间不新增定时查询。快速重复打开按最短 5 秒间隔合并，手动刷新复用 15 秒界面截止、12 秒 HTTP 超时和重复请求保护。

「关于与更新」将「检查更新」与蓝色主按钮「下载并自动更新」放在同一操作区。发现可用新版本后，点击主按钮沿用应用内下载、进度、校验、保存配置、退出旧进程、覆盖更新和重新打开的流程；未发现版本或更新进行中时禁用按钮。Gitee / GitHub 网页链接位于默认折叠的「手动下载备用入口（网页）」，明确与应用内更新区分。安装版使用静默安装，绿色版原位替换；下载与校验失败不替换旧版。

字段依据：2026-09-07 核对雷神[公开用户页面脚本](https://vip.leigod.com/js/user.js?6e66e093157e41080af9)，普通套餐的 `formatTime` 将 `expiry_time_samp + experience_time` 按秒转换，基础负值归零。`expiry_time` 不是时长字段。`expired_experience_time` 在没有活动时长时也可能等于服务器当前时间；只有到期时间晚于当前服务器时间才走活动分支。活动期间 `expiry_time_samp` 已含可暂停和不可暂停部分，不重复叠加体验时长。程序使用本次账户响应的 HTTP Date，按接口的 UTC+8 日期解释到期时间，不依赖用户电脑时钟；缺少有效时钟时沿用普通合计，不能仅凭到期字段存在判定余额不可用。

## 验证方法

原生桌面程序不使用浏览器预览替代实现。离屏验证直接调用正式 egui 界面、渲染器和字体，以测试配置输出截图；不启动托盘或监控线程，不读取实际账号、不执行暂停。比较侧栏、文案、版式、字号、色彩、按钮、列表及窄窗口适配；指针事件测试验证首页开关、延后、手动暂停、页面导航和名单操作。

本地使用 Windows 的 `Microsoft Basic Render Driver` 软件适配器，经 DirectX 12 输出 PNG。截图是实际组件、文本和布局的渲染结果，不是把概念图片贴进窗口。CI 与发版同样执行此项检查，并上传 `native-ui-*` 截图工件。

## 与确认概念的对照

| 检查项 | 实现与核对结果 |
| --- | --- |
| 页面骨架 | 保留左侧品牌导航、右侧概览；账户、策略、日志和更新使用同一套组件。 |
| 色彩 | 近白主背景、灰蓝侧栏、白色卡片、蓝色操作与青绿倒计时，已逐项比对。 |
| 标题层次 | 页面标题 27 px；分区与弹窗标题 20 px；正文 15 px，辅助文案 12–13 px。 |
| 首页操作 | 监控状态与总开关位于右上；延后和手动暂停位于主卡片下方，真实事件测试已验证。 |
| 倒计时与规则 | 圆环位于主卡片右侧；右侧摘要读取真实配置。并排卡片底部基本对齐。 |
| 游戏列表 | 分组圆角列表保留名称、进程、状态和更多菜单。使用文字图标，覆盖自定义游戏。 |
| 重启说明 | 蓝色浅底提示和微信小程序核对说明保留；完整触发条件在下方展开。 |
| 小窗口 | 680 × 460 与 940 × 660 改为纵向卡片，可滚动；自动断言主内容不横向溢出。 |

有意保留的差异：窗口边框和标题栏由 Windows 绘制；系统字体替代 Apple 字体；毛玻璃作用于应用内背景，不透出桌面；沿用原有盾牌品牌图标，游戏使用文字标识而非概念图的游戏商标。首页额外保留隐藏到托盘入口和完整规则展开项。原 0.9.0 对照表记录旧版设计，剩余时长与毛玻璃为用户本次要求的增量调整。

## 验证范围

- 真实组件的内存交互测试覆盖：总开关、准备游戏延后、手动暂停指令、导航、空账户输入校验、自定义游戏添加、更多菜单移除、GitHub / Gitee 来源切换及启动更新偏好。来源切换不发起下载。
- 进程状态测试覆盖大小写、完整进程名、无效名称、未知检测；检测失败会清除旧快照。启动检查待处理时检测失败仍可延后，完成后不重新开启。
- 截图覆盖首页、账户、策略、日志、更新和添加游戏窗口，以及小窗口与高 DPI 首页。测试状态完全独立于实际雷神账户。
- 该验证没有操作真实账户、实际游戏、关机流程或用户安装目录；软件适配器检查不等同于覆盖所有硬件显卡、OSD 与反作弊组合。

## 0.11.0 增量视觉核对

对照用户提供的启动保护卡片截图，保留原有标题、说明、准备游戏和立即暂停两项操作；有意新增账户时长区，并按要求调整背景与材质。使用正式 egui 组件及 DirectX 12 软件适配器离屏渲染，查看实际 PNG，不以浏览器网页或静态概念图替代原生程序。截图覆盖 1180 × 780、680 × 460 和 150% DPI。

| 项目 | 核对与修正 |
| --- | --- |
| 文案 | 原卡片标题、说明和两项操作保留；仅增加账户剩余时长、上次查询时间及刷新/登录入口，无额外营销文案。 |
| 布局 | 账户时长位于卡片左侧，启动等待圆环在右侧；宽屏规则卡片与主卡片等高，窄屏纵向滚动，无横向溢出。 |
| 字体 | 保留系统中文字体与原有标题层次；时长 25 px，小窗口按可用宽度调整，显示时/分/秒，清晰区分右侧 mm:ss。 |
| 毛玻璃 | 蓝绿紫背景执行真实高斯模糊并缓存；修正 gamma 目标的透明色混合，避免多层透明白饱和成实白，保留细亮边与柔和阴影。 |
| 可读性 | 文字与按钮不参与模糊；提高次级文字对比度，主按钮继续使用蓝底白字。 |
| 交互与状态 | 时长刷新期间标注旧结果并禁止重复点击；成功、失败、零值、未登录与切换账号均有离线覆盖。「去登录」使用真实指针事件验证。修正测试定位器对自动换行文字缩进的点击坐标计算。 |

本地离线单元测试 94 项通过；原生截图测试单独执行通过。测试使用演示数据，没有查询真实雷神账户，也没有启动用户应用、监控或游戏。毛玻璃为应用内效果，Windows 标题栏保留系统样式。真实账户时长及特殊套餐仍以官方刷新结果核对。

## 0.11.1 时长与自动刷新修复

针对「账户查询成功但首页余额不可用」，使用已有登录态做过一次只读账户信息诊断，核对服务端余额与用户提供的官方客户端截图一致，并确认无活动时长时也会返回活动到期时间。诊断只输出白名单中的计时字段，没有保存账户原始响应或凭据；没有调用暂停、恢复或登录接口。

回归数据使用独立演示值，覆盖活动到期时间等于、早于和晚于服务器时间、零活动时长，以及启动等待登录态恢复、账户页打开、托盘显式打开请求、窗口重新获得焦点、5 秒重复请求合并和后台不定时查询。所有原生渲染仍使用演示状态；保留原有布局、字体、颜色与毛玻璃，仅补充账户页自动刷新说明和准确的时长缺失提示。

开发者可执行以下命令重新生成截图，输出位于 `target/ui-preview/`：

```powershell
cargo test --locked --target x86_64-pc-windows-msvc ui::presentation_tests::render_apple_preview -- --ignored --nocapture
```
