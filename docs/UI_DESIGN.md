# 界面设计与验证

v0.12.0 按用户提供的 Serylane 界面参考重新设计雷神守护。采用浅白淡紫背景、浅色标题栏、线性导航、细边框分组与描边按钮，继续使用 Rust / egui 原生界面。参考图中的路由、代理等其他产品功能不属于本项目。

## 窗口与后台行为

标题栏支持拖动、双击最大化/还原、最小化和关闭；四边与四角支持原生缩放命令。最小化到任务栏；关闭与「隐藏到托盘」只隐藏窗口，后台监控继续。Alt+F4 仍按既有托盘逻辑处理，托盘「退出」立即退出。

开机静默启动继续使用 --minimized 和 v0.11.4 的 Win32 显示拦截。首次主动打开前只驻留托盘；点击托盘或再次运行快捷方式可打开。告警先写日志并暂存，主动打开后显示最新提醒；初始化失败保留可见面板。新标题栏在渲染阶段仅生成命令，原生隐藏由 App 更新阶段执行，离屏测试不操作用户窗口。

## 真实状态与交互

首页总开关写入原有策略；延后和立即暂停仍交给原监控指令处理。检测未就绪、空名单、无效进程名、停用、游戏运行和失败均显示实际状态，不推断暂停成功。游戏退出宽限期使用实际检测起点逐秒显示，后台状态改变即清除旧倒计时。

余额完整显示时、分、秒，例如「8941 时 15 分 01 秒」。只有接口确实返回零值才显示零，不在本机模拟扣费。查询期间保留上次结果并标明刷新；失败或异常显示暂不可用，未登录显示去登录。恢复登录后查询一次，重新打开面板及进入账户页自动刷新；前台首页/账户页每 60 秒查询，隐藏或失焦时不新增定时查询。重复打开最短间隔 5 秒，界面查询截止 15 秒、HTTP 超时 12 秒。

余额解析沿用 v0.11.1 的修复：普通套餐按 expiry_time_samp + experience_time 计算秒数，基础负值归零；活动到期时间等于服务器当前时间不能据此隐藏普通余额。以同次响应 HTTP Date 判断仍有效的活动，活动合计不重复叠加体验时长。计时结果仍以官方刷新为准。

添加游戏保留热门预设、自定义和运行进程选择，更多菜单可移除条目。三种登录方式、OSD 屏蔽与应用内更新沿用原有功能。下载必须由用户点击，完成进度、SHA-256 校验和配置保存后才更新；默认国内优先，保留严格单源选择，详见 [UPDATES.md](UPDATES.md)。

## 验证方法与结果

原生桌面程序不能通过浏览器页面验证，未制作网页替身。使用正式 egui 界面、系统字体和 DirectX 12 的 Microsoft Basic Render Driver 软件适配器离屏输出 PNG，再用图像查看工具对照用户参考、设计稿和最终截图。修正右侧数值列收缩、余额行过大空隙与窄窗口对齐问题；逐项核对标题栏、导航、背景、排版、边框、按钮和列表。整体风格已按设计稿验证，无未处理的主要视觉差异。

- 本地离线测试 106 项通过，另有 4 项明确忽略的截图/网络测试；截图测试单独执行通过。
- 内存指针事件验证总开关、延后、暂停、导航、游戏添加/移除、更新来源选择和账户查询状态。
- 新增标题栏最小化、最大化、拖动、右下角缩放命令及关闭只请求隐藏的验证；小窗口滚动可到达游戏操作，导航保持固定。
- 页面检查覆盖 680 × 460、940 × 660、1180 × 780；截图覆盖五个页面、添加游戏、账户成功/失败/等待、余额零值/未知/未登录，以及 150% DPI 的 1770 × 1170 首页。
- 独立 Win32 静默启动显示拦截回归继续通过。没有启动用户的实际应用、读取真实账户、调用暂停接口或操作运行中的游戏。离屏命令验证不等同于覆盖所有显示器、显卡、OSD 和反作弊组合。

有意差异：保留雷神守护品牌与真实功能；示例游戏文字标识纠正为 CS2 / PUBG / APEX；额外保留托盘入口和异常说明。系统字体与窗口外边角依运行环境而定，毛玻璃不透出桌面。信息较多时纵向滚动，底栏使用实际核对方法，不使用参考图的「非实时状态」。

生成截图（兼容既有 CI 命令名）：

```powershell
cargo test --locked --target x86_64-pc-windows-msvc ui::presentation_tests::render_apple_preview -- --ignored --nocapture
```

默认输出 target/ui-preview/，也可设置 LEIGOD_UI_PREVIEW_DIR；CI 与正式发版会上传 native-ui-* 截图工件。

## 0.12.1 滚动交互

主内容、日志、进程列表隐藏轨道与滑块，并在可继续滚动的上/下边缘绘制 10 px 淡色渐隐；相应边界到达后消失，内容未超出视口时两侧都不显示。添加游戏窗口同步隐藏滚动条。提示仅绘制少量渐变顶点，不增加定时重绘、后台任务或额外惯性动画。

保留 egui 原有滚轮/触控板平滑输入和边界约束。内容区域悬停或点击空白处后支持 Page Up / Page Down、Home / End；已聚焦的文本输入、带修饰键的组合和打开的下拉菜单不被接管，主页面在添加游戏或进程选择窗口打开时不响应翻页。键盘经与滚轮相同的滚动路径处理，确保日志上翻也能解除底部跟随。

长日志具有固定视口与独立滚动，避免把主页面无限撑高。停留底部时新记录自动跟随；滚轮或键盘上翻后，新记录不把阅读位置拉回底部；主动到底后恢复跟随。日志缓存数量与原有后台规则保持不变。

新增三项行为回归覆盖无轨道的完整可用宽度、滚轮与键盘的上下边界、边缘提示条件、输入框保护以及日志追加时的跟随/脱离/恢复。原生渲染新增长日志及最小窗口日志场景，结合现有首页滚动测试确认导航固定、底部内容可访问。
